✾LearnPulse+in progress Still blooming · is this student acting differently than usual? your pick
Most dropout models ask "is this student active enough?" I'm asking something else: "is this student acting differently than they usually do?" A quiet student going quiet isn't news. A busy student going quiet might be. LearnPulse is the pipeline I'm building to test that idea on the Open University Learning Analytics Dataset.
  • Every student gets their own baseline, built from daily activity, seven-day rolling windows, z-scores and gaps between logins
  • No student ever shows up in both training and validation, so the model can't cheat by remembering people
  • Side-by-side tests: raw activity vs. personal change vs. both together
  • Calibration and thresholds are picked from training data only, to keep the results honest
  • A growing pile of automated tests, because I don't trust code I haven't tested

✾Parkinson's Detection from Voice+health ML Can a few seconds of speech hint at Parkinson's? your pick
Parkinson's can change a person's voice before other signs show up. Using 195 voice recordings described by 22 acoustic measurements (things like jitter, shimmer and pitch), I compared eight classifiers to see which could tell the groups apart best.
  • KNN, Logistic Regression, Naive Bayes, SVM, Decision Tree, Random Forest, AdaBoost and XGBoost, each tuned with grid search
  • Stratified cross-validation and SMOTE to handle the imbalance between classes
  • Side-by-side charts of accuracy, precision, recall and F1, with an eye on recall, because missing a real case matters most here

A closer look · LearnPulse

Is "different from usual" a better warning sign than "less than average"?

Three models, one question. Model A only knows how active a student was this week. Model B knows how that compares to the student's own normal. Model C gets both. So far, knowing someone's normal seems to help.

Small print: these are early experimental results from one course run (OULAD module AAA, 2013J). The project is still in progress, and these aren't published findings.
